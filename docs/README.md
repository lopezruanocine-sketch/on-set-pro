# Documentación de On Set Pro

| Archivo | Qué es |
|---|---|
| `biblia-on-set-pro.md` | **La biblia del proyecto.** Qué es la app, principios, cada módulo con lo que entra y sale, qué está hecho y qué falta. Es el documento que manda. |
| `diagnostico-tecnico-2026-11-12.md` | Cómo estaba el código el 12/11/2026: inventario, problemas y plan de orden. |
| `originales/GDD-v3.0.rtf` y `.pdf` | Documento de diseño técnico original (febrero 2026), 8 bloques. |
| `originales/one-sheet-v5.2.pdf` | Documento técnico y comercial v5.2 (24/02/2026): propuesta de valor y fórmulas. |
| `originales/conversacion-gemini-58pag.txt` | La conversación de desarrollo con Gemini, extraída del PDF en texto plano para poder buscarla. |

## Cómo mantener esto

- Si una función nueva no está en la biblia, primero se escribe en la biblia y después se construye.
- Si una función se cambia o se quita, se actualiza la biblia en el mismo commit.
- Los PDF y RTF de `originales/` no se editan: son el registro histórico.
